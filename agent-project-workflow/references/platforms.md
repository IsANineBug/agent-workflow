## 2. 其他平台 — ⬜ 未验证

**目前没有第二个验证过的平台。** 这一节保持为空是有意的，不是遗漏。

新增平台时，复制下面的模板填写：

```markdown
| `wc` / `grep` | | |

| 子 agent / 并行执行 | | |
```

### 填写要求

1. **每一项都必须实际跑过才能填。** 没跑过的留空，并保持「⬜ 未验证」标记。
2. **不要抄其他平台的文档。** 官方文档写的是设计意图，不是这个 skill 的实测行为。
3. 平台名旁的标记只有两种：`✅ 已验证` / `⬜ 未验证`。不要发明第三种（比如「应该可以」）。
4. 验证方式要写成**别人能重跑**的动作，不要写「测试通过」。
